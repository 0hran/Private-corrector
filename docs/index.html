Chrome 127+ · Firefox 128+

Technical guide

Private Corrector

A browser extension for Chrome and Firefox that sends the text you select to Gemini, Claude or ChatGPT with ready-made instructions: correct with minimal changes, reformulate, shorten, make academic, convert to British or American English, explain, develop, find research papers, or run your own prompts. It uses your normal account on the AI website: no API key, no extra cost.

Install

Download the zip for your browser with the buttons at the top of this page (private-corrector-chrome.zip or private-corrector-firefox.zip, also on the releases page). The extension is not published in the Chrome Web Store or on addons.mozilla.org, so you load it yourself.

Chrome also Edge, Brave, Opera

  1. Unzip private-corrector-chrome.zip into a folder you keep. Chrome loads the extension from that folder, so don't delete it afterwards.
  2. Open chrome://extensions (Edge: edge://extensions).
  3. Turn on Developer mode, top right.
  4. Click Load unpacked and choose the folder.
  5. Optional: click the puzzle icon in the toolbar and pin Private Corrector.

It stays installed after a restart. To update: replace the folder's contents with the new version, then click the reload arrow on the extension's card.

Firefox

  1. Open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on…
  3. Choose private-corrector-firefox.zip (no need to unzip).

A temporary add-on is removed when Firefox restarts, together with its settings. To keep your settings between restarts, open about:config and set extensions.webextensions.keepStorageOnUninstall to true. To install it permanently, see Signing for Firefox.

First use

  1. Sign in to the AI website you will use, in the same browser: gemini.google.com (the default), claude.ai or chatgpt.com.
  2. Open the settings: right-click the toolbar icon, then Options (Chrome) or Manage Extension → Preferences (Firefox). You can also click ⚙ in the popup.
  3. Check the AI assistant and the other options, then click Save.

If the settings page shows a yellow banner about access to the AI sites, click Allow: the extension needs it to fill in the message box.

Using it

From the right-click menu

Select text, right-click, open Private Corrector → Gemini (the menu shows your default AI) and choose a function. Ask a question… first shows a small box for your question.

From the toolbar popup

Click the Private Corrector icon. The text you selected on the page is pasted in automatically. If nothing is selected in the browser, the popup pastes what you last copied with Ctrl+C, which is how you bring in text from Word, a PDF reader or an email client. Then:

  • Click one or several functions: they turn orange with a ✓.
  • Under Send to, choose the AI and either private chat or my default chat, for this prompt only.
  • Click Send. Double-click a function to send it alone right away.

Combining functions

Selected functions go to the AI in a single prompt. Rewriting functions (marked rewrite below) are applied together and give one rewritten text, for example Correct + British English or Shorten + Academic. The others each get their own section in the answer, after the rewritten text. British and American English can't be combined.

Functions

FunctionTypeWhat the AI is asked to do
Correct (minimal changes)rewriteFix spelling, grammar, agreement, punctuation and typography. Change a word only when it is wrong; no rephrasing, no translation. Reply with the corrected text only.
ReformulaterewriteRewrite clearly and fluently, keeping meaning, language, formality and roughly the length.
Make it more academicrewriteFormal academic register: precise vocabulary, objective tone, hedged claims. No invented data or citations.
ShortenrewriteCut by about a third (adjustable) while keeping key ideas, facts, figures and conclusions.
Convert to British Englishrewritecolour, organise, centre, flat, ‘single quotes’. Nothing else changed; non-English text is translated.
Convert to American Englishrewritecolor, organize, center, apartment, “double quotes”, periods inside quotes.
Develop / provide contentsectionExpand the ideas with explanations, arguments and examples; flag claims that need a source.
Suggest research paperssectionFull references (authors, year, title, venue, DOI), why each is relevant. Asked to check on the web and never invent a reference. Still verify each one.
ExplainsectionPlain-words summary, key ideas, technical terms, implicit context, a simple example; points out errors or debatable claims.
Ask a question…sectionYour own question or instruction about the selection.

Rewriting functions keep the language of the text. The others answer in the language of the text unless you set another one in the settings. To change an instruction, edit common/actions.js (see For developers).

Where prompts go

One AI window is reused for everything: by default a small floating window at the top right, sized to fit your screen. Two destinations:

Private chat (default)

A new chat that isn't saved in your history. While the window stays open, every prompt goes into that same chat; closing the window ends it. The extension only reuses it once it has confirmed that private mode is on.

AIPrivate modeHow the extension turns it on
GeminiTemporary chatOpens gemini.google.com/app and clicks the temporary chat button
ClaudeIncognito chatOpens claude.ai/new and clicks the ghost icon
ChatGPTTemporary chatOpens chatgpt.com/?temporary-chat=true

If the button can't be found or confirmed (after a site redesign, for example), a notification asks you to turn private mode on yourself before pressing Send.

My default chat

Every prompt goes into one chat you choose for each AI, kept in your history; the window always goes back to it. To set it: open the chat, then in the settings click Use the open chat next to that AI (or paste its address) and Save. An AI without a default chat uses its private chat.

Usage limits. The AI re-reads the whole chat at each message, so a long chat uses up your plan's limits faster and mixes in earlier texts. Close the private window or start a new default chat from time to time.

Saved tasks

Your own prompts, reusable in one click. They appear with a ★ in the right-click menu and in the popup, and combine with the built-in functions.

  • From the popup: select Ask a question…, type the instruction, click ★ Save this as a task, name it, click Save.
  • From the settings: My saved tasks → ＋ Add a task, edit or delete, then Save.
  • Tick Reply with the text only for tasks that transform the text (e.g. “Turn this into a polite, concise email”), so the result can be copied directly and merges with other rewriting functions.

The extension makes no network requests of its own and has no analytics. Your text reaches the AI only when you press Send, under that service's terms and your account's settings, exactly as if you had pasted it yourself. The selected text is wrapped in <text> tags and treated as material to work on, which makes instructions hidden in a web page less likely to take over. Still read the prompt before sending.

Troubleshooting

The prompt is not filled in

It is always copied to the clipboard too: click in the AI's message box and press Ctrl+V (⌘+V on a Mac). A notification says when this is needed. The usual cause is a redesign of the AI website; the message box selectors are in common/providers.js. Very long texts may appear as a “pasted text” attachment, as when you paste them yourself.

“Turn on temporary / incognito chat before you press Send”

The extension could not find or confirm the private-chat button. Turn it on in the AI window yourself, or close the window and try again. The next prompt starts a fresh chat, because an unconfirmed private chat is never reused.

Nothing happens on a PDF, a store page or a browser settings page

Browsers don't let extensions run on their built-in PDF viewer, their own pages (chrome://, about:) or their extension stores. Copy the text with Ctrl+C and use the toolbar popup.

Firefox forgets my settings after a restart

Temporary add-ons are removed at restart with their data. Set extensions.webextensions.keepStorageOnUninstall to true in about:config, or install the signed version (see Signing for Firefox).

“Combine several functions…” in the right-click menu does nothing

It opens the toolbar popup, which needs Chrome 127+ or a recent Firefox. If your browser refuses, a notification asks you to click the toolbar icon instead.

Chrome shows a warning about developer-mode extensions

Some Chrome versions and Edge remind you that an unpacked extension is installed. It is expected for extensions loaded with Load unpacked; dismiss it or keep it.

Build

./build.sh

Produces dist/private-corrector-firefox.zip and dist/private-corrector-chrome.zip, plus the unzipped folders. The Chrome manifest is generated from the Firefox one. The script overwrites files and deletes nothing; delete dist/ yourself after removing a source file.

Recent Chrome versions define a browser object of their own, without menus. compat.js therefore detects Firefox by browser.runtime.getBrowserInfo, which only Firefox has, and replaces the object everywhere else.

Tuning a function

Each entry in PC_ACTIONS (common/actions.js) has instructions (used when the function is sent alone), task (a short form used when it is combined), rewrite (true when the reply is the text only) and, for the others, section (the heading in a combined answer). {amount} in Shorten is replaced by the setting.

Adding an AI website

Add an entry to PC_PROVIDERS in common/providers.js: name, match (URL pattern), newChat, either privateUrl or privateButton + privateLabel, chatRe (address of a saved chat), chatExample and inputs (CSS selectors of the message box, best first). Add the site to host_permissions in extension/manifest.json and an option in the popup and settings page.

Signing for Firefox

Firefox installs unsigned extensions only temporarily. Mozilla signs private (“unlisted”) add-ons for free. Create API credentials at addons.mozilla.org → API keys, then run this in dist/firefox:

npx web-ext sign --channel=unlisted --api-key=YOUR_JWT_ISSUER --api-secret=YOUR_JWT_SECRET

Open the resulting .xpi in Firefox. Firefox Developer Edition and Nightly can also install unsigned add-ons when xpinstall.signatures.required is false.
