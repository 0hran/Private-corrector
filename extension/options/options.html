Private Corrector settings

The extension puts your selected text and the instructions for the action in the message box of a Claude page. You press Send yourself. It uses your normal Claude account (Free, Pro or Max): no API key, no extra cost. Make sure you are signed in to claude.ai in Firefox.

Firefox has not allowed this extension to fill in the message box on claude.ai yet.

When the Claude window opens, the extension starts a new chat and turns on incognito (ghost icon): the chat is not saved in your Claude history or memory. While the window stays open, every prompt goes into that same chat. Closing the window erases it, and the next action starts a new one. Close it from time to time: Claude re-reads the whole chat at each message, which uses up your usage limits faster. Incognito is not available for chats inside a project.

Correct, Reformulate and Academic always keep the language of the text.
