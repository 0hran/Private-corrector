Private Corrector settings

The extension puts your selected text and the instructions for the action in the message box of a Claude page. You press Send yourself. It uses your normal Claude account (Free, Pro or Max): no API key, no extra cost. Make sure you are signed in to claude.ai in Firefox.

Firefox has not allowed this extension to fill in the message box on claude.ai yet.

Where prompts go

The extension starts a new chat and turns on Claude's incognito mode (ghost icon): nothing is saved in your Claude history or memory. While the Claude window stays open, every prompt goes into that same chat. Closing the window erases it.

Every prompt goes into one Claude chat that you choose. The window always goes back to it, whatever it is showing. The chat is kept in your history.

Open the chat you want on claude.ai (in the Claude window or any tab), then click Use the chat open in Claude. Or paste its address. You can also switch between the two destinations for a single prompt in the toolbar popup (Send to). In either case, Claude re-reads the whole chat at each message, so a long chat uses up your usage limits faster.

My saved tasks

Your own prompts, available in the right-click menu (★) and the toolbar popup, where they can be combined with the other functions. Write the instruction as you would to Claude, for example “Make this email more polite and concise”. Tick Reply with the text only when the task transforms the text (so the result can be copied directly).

Other settings

Correct, Reformulate and Academic always keep the language of the text.
