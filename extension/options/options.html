Private Corrector settings

The extension puts your selected text and the instructions for the action in the message box of a Claude page. You press Send yourself. It uses your normal Claude account (Free, Pro or Max): no API key, no extra cost. Make sure you are signed in to claude.ai in Firefox.

Firefox has not allowed this extension to fill in the message box on claude.ai yet.

Every prompt goes into this one conversation, whatever the Claude page is showing. It is saved automatically when you send your first prompt. You can also paste the address of an existing chat (https://claude.ai/chat/…). Forget starts a fresh one at the next action; do that from time to time, because Claude re-reads the whole conversation at each message, which uses up your usage limits faster.

Correct, Reformulate and Academic always keep the language of the text.
