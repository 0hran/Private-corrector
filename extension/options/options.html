Private Corrector settings

By default, the extension sends your selected text to the Gemini API automatically and shows the answer in the Private Corrector window. You can choose instead to fill in the prompt on Claude, ChatGPT or Gemini's website (with your normal account), where you press Send yourself.

Firefox has not yet allowed this extension to fill in the message box on the AI sites.

AI assistant

You can pick another one for a single prompt in the toolbar popup (Send to).

Gemini API (automatic mode)

Free: open Google AI Studio → API keys, sign in, click Create API key and paste it here. It is stored only in this browser and sent only to Google's Gemini API.

Privacy on the free tier: Google may use what you send (and Gemini's answers) to improve its products, and human reviewers may read it. In the EU, the UK and Switzerland, Google applies its paid-tier data terms to free use too. To keep confidential text private, use a key from a Google Cloud project with billing enabled (paid tier), or a chat website in private mode. See Gemini API terms.

Flash models are fast and included in the free tier. If you hit the free-tier limit, try another model.

Chat websites

Used when you choose Claude, ChatGPT or Gemini (website) above or in the popup. Make sure you are signed in to them in Firefox.

A new chat that is not saved in your history: Claude's incognito chat, ChatGPT's or Gemini's temporary chat. While the AI window stays open, every prompt goes into that same chat. Closing the window ends it.

Every prompt goes into one chat that you choose for each AI, kept in your history. The window always goes back to it. Open the chat you want, then click Use the open chat next to that AI (or paste its address). If an AI has no default chat, its private chat is used.

A long chat uses up your usage limits faster (the AI re-reads it at each message): start a fresh one from time to time.

My saved tasks

Your own prompts, available in the right-click menu (★) and the toolbar popup, where they can be combined with the other functions. Write the instruction as you would to the AI, for example “Make this email more polite and concise”. Tick Reply with the text only when the task transforms the text (so the result can be copied directly).

Other settings

Correct, Reformulate and Academic always keep the language of the text.
